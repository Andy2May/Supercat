# Psiforge M1 Implementation Plan (2D core, wasm bindings, web sandbox)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Milestone M1 theo spec — core 2D (SplitOperator2D + FFT 2D), crate `wasm`, và app web Svelte 5 với heatmap WebGL2, vẽ thế bằng chuột, thả gói sóng, 60fps @512×512.

**Architecture:** Chiến lược H2 (xương sống dọc sớm): core 2D tối thiểu có test vàng → slice dọc wasm/worker/heatmap → đo perf 512×512 ngay → hoàn thiện core (builders, golden đầy đủ) → tương tác chuột + i18n → CI/Pages. Hai họ type song song (2D thêm hậu tố), không generic.

**Tech Stack:** Rust (rustfft 6, wasm-bindgen + js-sys, wasm-pack), Svelte 5 + Vite + TypeScript + WebGL2 (renderer imperative thuần), vitest + Playwright + wasm-bindgen-test + criterion.

**Spec:** `docs/superpowers/specs/2026-09-30-psiforge-m1-design.md` (mẹ: `docs/superpowers/specs/2026-09-29-psiforge-design.md`). Plan lập luận từ spec — executor đọc cả hai.

**Điều kiện tiên quyết (controller/user, không phải task):** user tạo GitHub repo và đưa URL cho controller để cấu hình remote + push trước khi chạy CI; môi trường đã có Node v24 + npm 11.

## Global Constraints

- Đơn vị tự nhiên ħ = m = 1 mặc định; `docs/units.md` là chuẩn quy đổi.
- Core tính f64; f32 chỉ xuất hiện ở ranh giới renderer (`density_phase`, `read_potential_f32`).
- Row-major mọi nơi: index phẳng `k = j·nx + i` (j theo trục y) cho ψ lẫn V; texture upload cùng thứ tự.
- rustfft unnormalized cả hai chiều; inverse tự áp 1/n; scratch luôn lấy từ `scratch_len`/`scratch2_len`, không hard-code.
- Norm guard: từ chối khi ‖ψ‖² không hữu hạn HOẶC lệch 1 quá `1e-10`; `NormDrift` mang ‖ψ‖² (bình phương); đếm bước u64; validate-before-mutate.
- Core deps khóa: `rustfft = "6"`, `num-complex = "0.4"`, `thiserror = "2"`; chỉ được thêm `criterion` (dev-dependency). Crate `wasm` deps: `psiforge-core`, `wasm-bindgen`, `js-sys` — không thêm gì khác.
- Sau mọi task đụng core: `cargo test --all` (45 unit + 6 golden M0 + 1 doctest) phải xanh nguyên vẹn; `cargo fmt --all --check` + `cargo clippy --all-targets -- -D warnings` sạch.
- Conventional commits; MIT; CI không fail theo hiệu năng (benchmark chạy cục bộ).
- Web: npm (không pnpm/yarn); mọi nhãn UI qua key i18n vi/en; logic nằm trong module TS thuần test được bằng vitest, component Svelte mỏng (không unit-test render Svelte).
- Semantics vẽ thế: paint GHI ĐÈ giá trị tuyệt đối trong hình dạng; xóa = paint 0; khôi phục nền giải tích = `restore_potential()` (xem Cờ quyết định #1).

## Cờ quyết định — controller phê chuẩn cùng plan

1. **Paint là ghi đè (SET), không phải cộng:** v1 spec §4.3 viết "nét vẽ tay cộng thêm", nhưng tẩy chỉ hợp lý với ghi đè (tẩy = paint 0). Trộn nền+tay đạt bằng workflow (vẽ trên nền đặt sẵn), không bằng phép cộng số học.
2. **Dung sai drift chuẩn 2D nới theo số điểm:** floor f64 scale theo √N điểm; pin test 2D ở `≤ 3e-12` sau 5×10³ bước @128² (1D-2048 đo được 1.2e-12 sau 10⁴). Đây là khoản chỉnh bảng test vàng §3.7 spec M1 (giống amendment §8.1 v1 hồi M0).
3. **Test năng lượng 2D có van runtime:** pin 128² × 10⁴ bước; nếu vượt 3 phút ở CI debug, hạ lưới còn 64² (dung sai không đổi) và ghi vào report.
